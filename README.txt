# RealNetMirror

A responsive, static movie-discovery website designed for shared hosting such as Hostinger.

## Upload to Hostinger
1. Extract this ZIP.
2. Open Hostinger File Manager.
3. Open `public_html`.
4. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
5. Visit your domain.

## Customize
Edit the `movies` array in `script.js` to add your own authorized movie/catalog data.
The poster cards currently use CSS artwork so the site works without external image dependencies.

## Important
Use only movie posters, video files, streams, trailers, and download links that you own or are authorized to publish.
